# simuladores-financeiros
Projeto idealizado e revisado por Lélis Andrade, desenvolvido com auxílio do ChatGPT na geração do código. As premissas financeiras e os resultados foram conferidos pelo responsável pelo projeto.

## Recursos

- [Laboratório de decisões de investimento](https://andradelelis.github.io/simuladores-financeiros/): simulador de fluxo de caixa, cenários, sensibilidade, pontos de equilíbrio e GAO.
- [Aplicativo Shiny de análise de demonstrações financeiras](https://lelis-pedro-andrade.shinyapps.io/app-dfcs/): ferramenta em R/Shiny publicada no shinyapps.io.
